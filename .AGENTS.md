# Global AI Agent Instructions

## Code & Execution Constraints
- **Context & Token Conservation:** Never read files over 400 lines (use `grep` and specific line ranges `offset`/`limit`), ignore build artifacts (`build/`, `DerivedData/`, `.venv/`, `node_modules/`, `*.o`, disassembly dumps), and delegate multi-file searches to the `@explore` subagent.
- **Concise Output:** Skip conversational filler; state the root cause or plan briefly and execute the patch.
- **Git Hygiene:** Never include mentions of agents in commits (e.g., `Contributed-by`) unless explicitly requested. Use MIT `LICENSE.md` with no License section in the README.

## Testing & Automation
- **Autonomous Testing:** Run test suites and build checks autonomously, but **always** wrap commands in the macOS non-blocking Perl timeout wrapper (never use Linux `timeout` or background sleep hacks): 
  `perl -e 'alarm shift; exec @ARGV' 60 [command]`
- **Log Management:** Pipe noisy build or test logs through `head`/`tail` (e.g., `2>&1 | head -n 50`) and resolve errors until CI/CD is green.
- **CI/CD & Environments:** Avoid macOS/iOS GitHub runners; use Linux/container runners. Use `mise` for environments or `docker`/`docker-compose` for module installation, services, and containerized tests. Create Dockerfiles to package and deploy services.
- **Database Migrations:** Ship migrations for any code changes touching a backend database.

## Platform Standards (macOS & Cloud)
- **Native macOS Apps:** Create macOS `zsh`-compatible build, run, test, and notarization scripts; scaffold Xcode Cloud CI/CD where appropriate; ensure macOS app icons fill the squircle.
- **Cloud Deployments:** Create macOS `zsh`-compatible deployment, update, and teardown scripts native to Azure or GCP when a cloud target is specified.
