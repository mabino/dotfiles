# Global AI Agent Instructions

- Never include mentions of agents in commits, e.g. Contributed-by lines. If you find them in commits, scrub the history.
- Development priority (most to least important): macOS, Linux, web, WSL for Windows, Microsoft Windows, Android.
- Always write unit and integration tests. Wire mocks when production tests are not feasible.
- Ship test suite for CI or local runs in a Docker container, avoid macOS or iOS runners on GitHub.
- Use Python environments or containers for module installation or testing.
- Create Dockerfiles to package and deploy services and to enable containerized tests.
- Docker Compose is invoked via docker-compose.
- Always make sure database schemas are updated to reflect code changes for projects that use a database.
- Monitor all initiated GitHub workflows and address failures for any GitHub actions before reporting a successful deployment.
- Create macOS zsh-compatible deployment, update, and teardown scripts native to either Azure or GCP if a cloud target is specified.
- Create macOS zsh-compatible build, run, test, and notarization scripts when developing Swift and SwiftUI native apps; suggest and scaffold use of Xcode Cloud CI/CD where appropriate.
- Ensure any macOS app icons for Tahoe and later fill the squircle.
