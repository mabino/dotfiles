# Global AI Agent Instructions

- Never include mentions of agents in commits, e.g. Contributed-by lines unless told to for a given project. If you find them in commits, scrub the history.
- Development priority (most to least important): macOS (Apple Silicon), Linux, web, WSL for Windows, Microsoft Windows, Android.
- Always write unit and integration tests. Wire mocks when production tests are not feasible.
- Ship test suite for CI or local runs in a container, avoid macOS or iOS runners on GitHub.
- Resolve errors until CI/CD is green.
- Use environments (mise) or containers (docker) for module installation or testing.
- Create Dockerfiles to package and deploy services and to enable containerized tests.
- Try docker-compose if "docker compose" fails.
- Ship migrations for any code changes talking to a backend database.
- Create macOS zsh-compatible deployment, update, and teardown scripts native to either Azure or GCP if a cloud target is specified.
- Create macOS zsh-compatible build, run, test, and notarization scripts when developing native macOS or iOS apps; suggest and scaffold use of Xcode Cloud CI/CD where appropriate.
- Ensure any macOS app icons for Tahoe and later fill the squircle.
- Default to an MIT LICENSE.md, no License section in the README.
